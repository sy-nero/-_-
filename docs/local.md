# הרצה על המחשב, עם נתונים ומדידה בענן

השילוב הזה חינמי לגמרי, ומחלק כל חלק למקום שמתאים לו:

| חלק | איפה רץ | למה שם |
| --- | --- | --- |
| הלוח, הסריקה, השליחה | המחשב שלך | אין שינה, אין תקרת זיכרון, הסריקה מהירה יותר |
| כל הנתונים | Cloudflare D1 | בענן, נשמרים תמיד, נגישים מכל מחשב |
| מעקב פתיחות | Cloudflare Worker | חייב להיות ער תמיד, כי הנמען פותח מתי שבא לו |

מה שמוותרים עליו: אי אפשר לפתוח את הלוח מהטלפון. הוא רץ על המחשב.

## 1. הפעלה

לחיצה כפולה על **`start.command`** בתיקיית הפרויקט. בפעם הראשונה זה מכין
סביבה ומתקין חבילות (דקה), ואחר כך פותח את הלוח בדפדפן לבד.

לעצירה: לסגור את החלון.

בפעם הראשונה macOS עשוי לומר שהקובץ מגורם לא מזוהה — קליק ימני על הקובץ,
"Open", ואז "Open" שוב. זה חד־פעמי.

## 2. הנתונים — כבר עובד

זה החלק שלא דורש שום עבודה: האפליקציה קוראת את הגדרות D1 ממשתני הסביבה,
ולכן **מרגע שהם בקובץ `.env` המקומי, כל סריקה וכל שליחה נכתבות ישר למסד
שבענן** — אותו מסד שהיה בשימוש עד היום.

בקובץ `.env` צריכים להיות:

```
D1_ACCOUNT_ID=...
D1_DATABASE_ID=...
D1_API_TOKEN=...
```

`D1_ACCOUNT_ID` הוא 32 תווים בלי מקפים. `D1_DATABASE_ID` הוא UUID עם מקפים.
**אלה שני דברים שונים ואסור להחליף ביניהם** — זו הייתה תקלה שעלתה שעות.

בלי שלושת אלה האפליקציה תיפול חזרה לקובץ מקומי, והנתונים לא יגיעו לענן.

## 3. מעקב הפתיחות — Worker שרץ תמיד

האפליקציה כבויה כשהמחשב כבוי, אבל הנמען פותח את המייל מתי שבא לו. לכן
הפיקסל יושב בנפרד, ב-Cloudflare Worker: 42 בתים של תמונה ושורה אחת
שנכתבת ל-D1. תמיד ער, בלי זמן התעוררות, ובחינם (100,000 בקשות ביום —
תשתמשי בכמה עשרות).

### התקנה, פעם אחת

```
npm install -g wrangler
cd tracking-worker
wrangler login
```

לפני הפריסה: לפתוח את `wrangler.toml` ולהחליף את `PUT-YOUR-D1-DATABASE-ID-HERE`
ב-`D1_DATABASE_ID` שלך (אותו ערך שב-`.env`). לוודא גם ש-`database_name` הוא
שם המסד כפי שהוא מופיע ב-Cloudflare.

```
wrangler deploy
```

בסוף מודפסת כתובת כמו `https://sy-nero-tracking.<שם>.workers.dev`.

### לחבר אותה למיילים

בקובץ `.env`:

```
TRACKING_BASE_URL=https://sy-nero-tracking.<שם>.workers.dev
```

זהו. כל מייל שיישלח מעכשיו יכיל פיקסל שמצביע ל-Worker, וכל פתיחה תיכתב
ל-D1 — כך שהמספרים בלוח מתעדכנים לבד, גם כשהמחשב כבוי.

### בדיקה

```
curl -i https://sy-nero-tracking.<שם>.workers.dev/px/test123456.gif
```

צריך לחזור `200` עם `Content-Type: image/gif` ו-42 בתים. מזהה שלא קיים
במסד מחזיר תמונה תקינה ופשוט לא רושם כלום — זה מכוון.

## מה שחשוב לדעת על המספרים

מעקב פתיחות אף פעם אינו מדויק, בשום כלי:

* תוכנות מייל רבות חוסמות תמונות — פתיחה כזאת לא נספרת, ולכן **המספר
  האמיתי גבוה ממה שרואים**.
* Gmail טוענת תמונות דרך שרת מטמון שלה, ולכן לפעמים נספרת "פתיחה"
  כשההודעה רק נסרקה.

להתייחס למגמה ולהשוואה בין נוסח א' לנוסח ב', לא למספר המוחלט.
