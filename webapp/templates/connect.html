חיבור לשיחת החיפוש

איך זה עובד

שיחת החיפוש ב-Claude מוצאת עסקים, ובסוף שולחת את הרשימה לכתובת של הלוח. הרשימה עוברת את כל הבדיקות של העלאת קובץ (כפילויות, מי שכבר קיבל, ספקים ישנים) ומופיעה בקמפיין שבחרת, מוכנה לשליחה. מעתיקים את ההנחיה למטה לשיחת החיפוש פעם אחת.

המפתח

כמו סיסמה: לא משתפים אותו מחוץ לשיחת החיפוש

ההנחיה לשיחת החיפוש

כשאת/ה מסיימ/ת חיפוש של עסקים, שלח/י את התוצאות ישר ללוח הקמפיינים, במקום להחזיר לי קובץ.

1. קודם בודקים לאיזה קמפיין לשלוח:
curl -s {{ base }}/api/campaigns -H "Authorization: Bearer {{ token }}"

2. שולחים את הרשימה (JSON), עם מספר הקמפיין שאמרתי לך:
curl -s -X POST {{ base }}/api/import \
  -H "Authorization: Bearer {{ token }}" \
  -H "Content-Type: application/json" \
  -d '{"campaign_id": 40, "group": "אולמות אירועים",
       "rows": [{"name": "שם העסק", "email": "mail@example.com", "phone": "050-0000000",
                 "city": "ירושלים", "first_name": "", "group": "אולמות אירועים"}]}'

שדות: name, email (חובה), phone, city, first_name, group.
אפשר גם לשלוח CSV שלם: {"campaign_id": 40, "csv": "שם,מייל,טלפון\n..."}

3. התשובה אומרת כמה נוספו, כמה לא ולמה. תמסור/י לי את הסיכום.
אם לא אמרתי לאיזה קמפיין, תשאל/י אותי לפני השליחה.
